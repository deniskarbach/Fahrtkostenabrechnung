# S1 – Reisekostenabrechnung

Amtliches Formular, Seite 1. Kopf (A3/E3/J3) aus Setup, ab Zeile 7 je Spalte ein
Zeitraum-Auszug aus BERECHNUNG (Muster B).

## A3 / E3 / J3 - Kopfdaten

```
A3: =TEXTJOIN(" "; TRUE; Setup!C17; Setup!C19) & ", " & TEXTJOIN(" "; TRUE; Setup!C61) & "-" & TEXTJOIN(""; TRUE; Setup!C63)
E3: =TEXTJOIN(" "; TRUE; Setup!C26; Setup!C28) & "," & TEXTJOIN(" "; TRUE; Setup!C30; Setup!C32)
J3: =TEXTJOIN(" "; TRUE; Setup!C48; Setup!C50) & ", " & TEXTJOIN(" "; TRUE; Setup!C52; Setup!C54)
```

| Zelle | Ergebnis |
|---|---|
| A3 | „Vorname Name, Organisationseinheit" |
| E3 | „Straße Nr., PLZ Ort" der antragstellenden Person |
| J3 | Anschrift des Dienstorts |

**Statement:** `TEXTJOIN(" "; TRUE; …)` verbindet Setup-Felder mit Leerzeichen
(`TRUE` lässt leere Felder weg), feste Trennzeichen (`, ` bzw. `-`) zwischen den Gruppen.


## A7 - Reisedatum

```
=ARRAYFORMULA(IFERROR(FILTER(
  LET(start; TEXT(BERECHNUNG!C3:C;"DD.MM.YYYY");
      ende; TEXT(BERECHNUNG!E3:E;"DD.MM.YYYY");
      IF(OR(BERECHNUNG!C3:C=BERECHNUNG!E3:E; BERECHNUNG!E3:E="");
         start; start&" - "&ende));
  BERECHNUNG!C3:C<>"";
  BERECHNUNG!C3:C>=Setup!$C$8;
  BERECHNUNG!C3:C<=Setup!$C$10
);""))
```

**Ergebnis:** Pro Reise ein Datum, bei mehrtägigen Reisen „Start - Ende".
**Rechenweg:** Start- und Enddatum werden formatiert; sind sie gleich (oder Ende leer), erscheint nur ein Datum.
**Muster:** Zeitraum-Auszug (B).


## D7 - Reiseweg

```
=ARRAYFORMULA(IFERROR(FILTER(
  "Nr. "&BERECHNUNG!A3:A
  &"  –  ("&"Ges.: "&TEXT(BERECHNUNG!S3:S/24;"[H]:MM")
  &" | DSt: "&TEXT(BERECHNUNG!Q3:Q/24;"[H]:MM")
  &" | DO: "&TEXT(BERECHNUNG!R3:R/24;"[H]:MM")
  &IF(BERECHNUNG!T3:T>0;" | Priv: "&TEXT(BERECHNUNG!T3:T/24;"[H]:MM");"")
  &" | Rest: "&TEXT((BERECHNUNG!S3:S-BERECHNUNG!T3:T-BERECHNUNG!Q3:Q-BERECHNUNG!R3:R)/24;"[H]:MM")&")";
  BERECHNUNG!C3:C<>"";
  BERECHNUNG!C3:C>=Setup!$C$8;
  BERECHNUNG!C3:C<=Setup!$C$10
);""))
```

**Statement:** `/24` rechnet Dezimalstunden in den Tagesbruch zurück, den
`TEXT(…;"[H]:MM")` als Zeit über 24h formatieren kann.

**Ergebnis:** Eine Textzeile je Reise mit Nummer und allen Zeiten, z. B.
`Nr. 3 – (Ges.: 9:15 | DSt: 1:00 | DO: 4:30 | Rest: 3:45)`.
**Sonderfall:** Der Priv-Teil erscheint nur, wenn der private Abzug größer als 0 ist.
**Muster:** Zeitraum-Auszug (B).


## B7:N7 - Zeitraum-Auszüge

Alle folgenden Zellen sind reine `FILTER(BERECHNUNG!Spalte; Muster B)`-Auszüge:

```
=ARRAYFORMULA(IFERROR(FILTER(BERECHNUNG!<Spalte>3:<Spalte>; BERECHNUNG!C3:C<>""; BERECHNUNG!C3:C>=Setup!$C$8; BERECHNUNG!C3:C<=Setup!$C$10);""))
```

| Zelle | Quelle (BERECHNUNG) | Ergebnis | Nur wenn > 0 |
|---|---|---|---|
| B7 | D | Uhrzeit Reisebeginn | |
| C7 | F | Uhrzeit Reiseende | |
| E7 | M | Tagegeld anteilig ≤8h (Kreuz) | |
| F7 | N | Tagegeld >8h (Kreuz) | |
| G7 | O | Tagegeld ≥14h (Kreuz) | |
| H7 | P | Tagegeld 24h (Kreuz) | |
| I7 | U | Verpflegung | |
| J7 | V | Fahrtkosten ÖPNV | ✓ |
| K7 | K | Fahrtkosten Wegstrecke bereinigt | |
| L7 | W | Mitnahme Personen | ✓ |
| M7 | X | Übernachtungskosten | ✓ |
| N7 | Y | Nebenkosten | ✓ |

Zellen mit „Nur wenn > 0" wickeln die Quelle in `IF(BERECHNUNG!Spalte>0;…;"")`
ein, bevor gefiltert wird — ein Wert von 0 erscheint als leere Zelle statt „0".
